# NightSleep-Monitor

NightSleep-Monitor — это крошечная утилита для Windows 11 и Windows 10 (не самых старых версий), которая затемняет экран глубже, чем позволяет ползунок яркости.

## Как установить

Скачайте из раздела [актуальную версию](https://github.com/ohdgg/nightsleep-monitor/releases), распакуйте архив. Установка не требуется, просто запустите. NightSleep-Monitor появится в трее Windows.

При первом запуске Windows SmartScreen покажет синее окно: нажмите «Подробнее» и «Выполнить в любом случае».

NightSleep-Monitor не собирает никакой аналитики.

## Горячие клавиши изменить нельзя

| Действие                          | Хоткей по умолчанию  |
| --------------------------------- | -------------------- |
| Темнее                            | `Ctrl+Alt+PageDown`  |
| Светлее                           | `Ctrl+Alt+PageUp`    |
| Вкл/выкл (0% ↔ последний уровень) | `Ctrl+Alt+End`       |
| Аварийный сброс до 0%             | `Ctrl+Alt+Shift+End` |

Подробнее на сайте [datamvp.top](https://datamvp.top/)
