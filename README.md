# NightSleep-Monitor

NightSleep-Monitor is a tiny utility for Windows 11 and Windows 10 (not the oldest builds) that dims the screen deeper than the standard brightness slider allows.

## Installation

Download the [latest release](https://github.com/ohdgg/nightsleep-monitor/releases) and extract the archive. No installation is required — just run the executable. NightSleep-Monitor will appear in the Windows system tray.

On first launch, Windows SmartScreen may show a blue warning dialog: click **More info** and then **Run anyway**.

NightSleep-Monitor does not collect any analytics.

## Hotkeys Cannot Be Changed

| Action                             | Default Hotkey       |
| ---------------------------------- | -------------------- |
| Darker                             | `Ctrl+Alt+PageDown`  |
| Lighter                            | `Ctrl+Alt+PageUp`    |
| Toggle (0% ↔ last level)           | `Ctrl+Alt+End`       |
| Emergency reset to 0% (0% dimming) | `Ctrl+Alt+Shift+End` |

More details on [datamvp.top](https://datamvp.top/)
