# NightSleep

Крошечная утилита трея для Windows, которая затемняет экран глубже, чем позволяет ползунок яркости. Чистый Rust + Win32: без WebView, без фреймворков, один exe.

Tiny Windows tray utility for deep screen dimming. Pure Rust + Win32, a single small exe.

> **Статус: ранний прототип (этап 1 по [ТЗ](docs/NightSleep_TZ.md)).** Код ещё ни разу не запускался на Windows: сначала нужно проверить, что сборка проходит в CI и что оверлей держится поверх панели задач.

## Как это работает

Поверх рабочего стола на каждом мониторе показывается чёрное полупрозрачное окно, пропускающее мышь и клавиатуру сквозь себя. Уровень затемнения задаёт его прозрачность. Яркость подсветки и гамма видеокарты не меняются.

## Управление

| Действие | Хоткей по умолчанию |
|---|---|
| Темнее | `Ctrl+Alt+PageDown` |
| Светлее | `Ctrl+Alt+PageUp` |
| Вкл/выкл (0% ↔ последний уровень) | `Ctrl+Alt+End` |
| Аварийный сброс до 0% (не настраивается) | `Ctrl+Alt+Shift+End` |

Левый клик по иконке в трее включает и выключает затемнение, правый открывает меню с уровнями, автозапуском и выходом. Максимум затемнения по умолчанию 90%.

Что уже есть: оверлей на всех мониторах, хоткеи, трей, меню, автозапуск, сохранение настроек в `%APPDATA%\NightSleep\config.ini`, лог, русский и английский языки.
Чего ещё нет: окно настроек (хоткеи и шаг пока меняются правкой `config.ini`).

## Методы затемнения

| Метод | Как работает | Статус |
|---|---|---|
| `overlay` (по умолчанию) | Чёрные click-through окна поверх каждого монитора | Стабильный. Не может перекрыть меню «Пуск» и панель задач при открытом «Пуске» в Windows 11 |
| `magnifier` | Цветовая матрица Magnification API применяется ко всему рабочему столу | **Эксперимент.** Должен затемнять и «Пуск», и панель задач, миниатюры, Peek. Один уровень на все мониторы; может конфликтовать со встроенной «Экранной лупой» (`Win` + `+`) и цветовыми фильтрами Windows |

Переключение: правый клик по иконке в трее → блок «Метод затемнения». Выбор запоминается в `config.ini` (`method=overlay` или `method=magnifier`).

### Если что-то пошло не так

1. Аварийный хоткей `Ctrl+Alt+Shift+End` сбрасывает затемнение до 0% в любом методе.
2. В меню трея выберите «Оверлей (стабильный)»: приложение вернётся к прежнему методу.
3. Если метод Magnifier не запустился, приложение само включит оверлей, запомнит это и покажет уведомление; подробности в `%APPDATA%\NightSleep\log.txt`.
4. Если экран остался затемнённым после сбоя: закройте NightSleep и выполните `nightsleep.exe --reset-screen`.
5. Если приложение не запускается из-за метода: `nightsleep.exe --method=overlay` или правка `method=overlay` в `config.ini`.

## Параметры командной строки

| Параметр | Действие |
|---|---|
| `--reset` | Сбросить сохранённый уровень на 0% |
| `--method=overlay` / `--method=magnifier` | Выбрать метод затемнения (запоминается) |
| `--reset-screen` | Снять цветовой эффект Magnification, если он остался после сбоя, и выйти |
| `--cleanup` | Снять цветовой эффект, удалить автозапуск и папку `%APPDATA%\NightSleep`, затем выйти |

## Ограничения

- Эксклюзивный полноэкранный режим игр (DirectX/Vulkan): оверлей не виден. Режим «окно без рамки» работает.
- Окна UAC (secure desktop) не затемняются.
- Часть системных окон Windows 11 (Пуск, быстрые настройки, центр уведомлений) находится в более высоком слое и может оставаться не затемнённой. Обойти это можно только с подписанным exe и `uiAccess`, что не подходит для portable-версии.
- Миниатюры панели задач и подсказки появляются поверх оверлея на долю секунды, после чего оверлей поднимается над ними.
- Затемнение попадает на скриншоты.
