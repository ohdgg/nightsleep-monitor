# NightSleep

Крошечная утилита трея для Windows, которая затемняет экран глубже, чем позволяет ползунок яркости. Чистый Rust + Win32: без WebView, без фреймворков, один exe.

Tiny Windows tray utility for deep screen dimming. Pure Rust + Win32, a single small exe.

> **Статус: ранняя версия (этапы 1–2 по [ТЗ](docs/NightSleep_TZ.md)).** Проверена на Windows 11. Окна настроек пока нет.

## Как это работает

Затемнение выполняется системным API Magnification (`MagSetFullscreenColorEffect`): к изображению всего рабочего стола применяется цветовая матрица, которая умножает яркость каналов R, G и B на коэффициент от уровня затемнения. Это происходит при сборке кадра, поэтому затемнение действует и на меню «Пуск», панель задач, миниатюры, подсказки и Aero Peek. Яркость подсветки и гамма видеокарты не меняются. Окон поверх экрана программа не создаёт.

## Управление

| Действие | Хоткей по умолчанию |
|---|---|
| Темнее | `Ctrl+Alt+PageDown` |
| Светлее | `Ctrl+Alt+PageUp` |
| Вкл/выкл (0% ↔ последний уровень) | `Ctrl+Alt+End` |
| Аварийный сброс до 0% (не настраивается) | `Ctrl+Alt+Shift+End` |

Левый клик по иконке в трее включает и выключает затемнение, правый открывает меню с уровнями, автозапуском и выходом. Максимум затемнения по умолчанию 90%.

Что уже есть: затемнение, хоткеи, трей, меню, автозапуск, сохранение настроек в `%APPDATA%\NightSleep\config.ini`, лог, русский и английский языки.
Чего ещё нет: окно настроек (хоткеи и шаг пока меняются правкой `config.ini`).

## Если что-то пошло не так

1. Аварийный хоткей `Ctrl+Alt+Shift+End` сбрасывает затемнение до 0%.
2. Выход из программы (меню трея → «Выход»), завершение сеанса и аварийное падение приложения возвращают нормальную яркость.
3. Если Windows не позволяет применить затемнение, программа сбросит уровень до 0%, покажет уведомление и запишет причину в `%APPDATA%\NightSleep\log.txt`. Запасного метода затемнения нет.
4. Если экран остался затемнённым после сбоя или принудительного завершения процесса: выполните `nightsleep.exe --reset-screen`.

## Параметры командной строки

| Параметр | Действие |
|---|---|
| `--reset` | Сбросить сохранённый уровень на 0% |
| `--reset-screen` | Снять цветовой эффект Magnification, если он остался после сбоя, и выйти |
| `--cleanup` | Снять цветовой эффект, удалить автозапуск и папку `%APPDATA%\NightSleep`, затем выйти |

## Ограничения

- Один уровень затемнения на все мониторы сразу.
- Встроенная «Экранная лупа» Windows (`Win` + `+`) и цветовые фильтры могут конфликтовать с затемнением, так как используют тот же механизм. Не проверялось.
- Эксклюзивный полноэкранный режим игр, защищённый рабочий стол (окна UAC), HDR-мониторы и попадание затемнения на скриншоты не проверялись.
- Остался ли эффект на экране после принудительного завершения процесса (Диспетчер задач), не проверялось: на этот случай есть `--reset-screen`.

